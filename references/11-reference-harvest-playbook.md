# 参考资料取证手册（通道、API、限流与零结果登记）

本册只讲**怎么把参考搞到手、怎么证明搞到了什么、搞不到时怎么留痕**。它不判断"像不像"（那是 `04`/`06` 的事），也不定义主数据的注册方式（那是 `02`）。

## 0 唯一目标与边界

- 目标：让**每一条几何都能指回一个带等级的证据 ID**；并让"搞不到"也变成一条可查的结论。
- 不覆盖：非公开渠道、绕过登录/付费墙、把二手图当一手用、把渲染图当块级主数据。
- 通道可用性随网络环境与站点策略变化：**换环境必须重测**；本册保证的是"失败也有记录"，不保证任何通道长期可用。

## 1 通道选择矩阵（实测，按"最省 → 兜底"排序）

| 通道 | 手段 | 适用 | 注意事项 |
|---|---|---|---|
| 站点自带 API（MediaWiki / BBS / 游戏开放接口） | `requests` / `curl` | 结构化数据、图集、帖子正文 | 先确认参数名；异常参数可能返回**空结果而不是报错** |
| 静态镜像站 | `requests` | 原站被反爬拦时的同源替代 | 等级降一档（镜像 ≠ 一手），但内容可与原站交叉校验 |
| 浏览器自动化 | 真浏览器 | 过 Cloudflare / JS 渲染 / 需要站内登录态 | 可在页面内**同源 `fetch`** 调该站 API，绕过对裸 `requests` 的封锁 |
| 官方社区 API | `requests` | 游戏内实拍、玩家考据、官方号发布 | 通常**限流**：返回体里字段变空而不是返回 429 |
| 官方地图瓦片 | `requests` | 平面足迹、台地轮廓 | 俯视平面**原理上给不出高度/层数** |
| 官方视频/图文发布 | 站内页面 + 抽帧 | 对象定义、宣发外形 | 宣发 CG 有 VFX 外溢，**不能当几何量测口径** |

**实测记录（2026-09-22，本机；换环境需重测）**

- `zh.minecraft.wiki`：裸 `requests` → **403 Cloudflare 质询页**；**真浏览器可过**，且在其中同源
  `fetch('/api.php?action=parse&page=<title>&prop=wikitext&format=json&formatversion=2')`
  可直接取到**结构蓝图 wikitext**（本册见到的最高价值主数据形态）。
- `wiki.biligame.com`：裸 `requests` 可用（同源镜像，图可直接下载）→ 原站被拦时的首选替代。
- Fandom 全系：**连接超时**，不可用。
- 米游社 BBS：`getPostFull?post_id=<id>&read=1` 可用；**连续快请求会让 `images` 变空数组**（限流表现），需每帖间隔 ≥1.2s；`searchPosts?keyword=&size=` 可用，但**带 `gids` 参数会返回空结果**。
- bilibili search API：**403**（需 cookie/wbi）。
- TapTap：站内搜索页无结果、`webapiv2/search/v4` **404**；**应用直链页可用**（先拿到正确 app id）。
- 官方地图瓦片：`api-takumi-static.mihoyo.com/.../map/info?map_id=<n>` 可取 slice 网格与 tile URL，用于平面注册。

## 2 标准取证动作（六步）

1. **先搜关键词并记账**：每个关键词记「结果数 / 是否命中 / 污染情况」。这份记账本身就是"零结果"的证据。
2. **先落原始件，再解析**：HTML / JSON / 图片先原样存盘，解析脚本单独写；两者分离才能事后复核。
3. **逐图登记**：`url + 页面 URL + 抓取日期 + 原标题`（`_img_index.json` 之类）。
4. **来源分级**并写进来源表：A 一手官方 / B 权威镜像或官方社区实证 / C 二手或玩家创作 / D 不可用。
   **等级必须能随实测下调**（本项目出现过把一张带坐标轴调试图评为 A 并用于足迹比对的实例，后被实测证伪降为 D）。
5. **写可复现脚本**：幂等（已存在且大于阈值则跳过）；脚本 docstring 里写明**哪些通道失败、为什么**——失败信息是资产。
6. **零结果也要写**：搜过的渠道、关键词、结果数、结论。"未获 A 级确认"是**结论**，不是失败。

## 3 反爬、限流与污染

### 3.1 浏览器自动化的精确调用（实测坑）

- 浏览器工具的“执行 JS”**必须传函数源码**，例如 `request.fn = "() => { ... }"`。传 `request.expression`、或传裸表达式字符串，各自报不同错误（前者提示需要 fn，后者提示“source did not produce a function”）。
- 该后端的**截图 action 可能不可用**（报实现层错误）。替代路径：在页面内用 **canvas 抽帧**，再把帧交付本地工具读取。
- `open` 偶发 5s 超时；改走 `navigate` 即成功。

### 3.2 从视频里取参考帧
从 `<video>` 元素经 canvas 抽帧可行，且实测**未被 CORS 污染**（跨域视频通常会污染 canvas）；用 `?t=<秒>` 可粗定位到目标画面。**代价：HUD / 字幕 / 水印会一起进来**，直接决定该帧能不能当量测口径。

### 3.3 同名作品污染（反直觉，必记）
实测结论：**对象名 / 赛季名抗污染，部件名不抗污染**。例：搜“<游戏> <赛季名>”能出官方结果；搜“<游戏> <赛季名> <部件名>”反而被同名影视作品占满（20 条里 0 条相关）。而部件名恰好是最容易想到的第一个搜索词。

四个实用筛子：**① 作者是不是官方账号；② 发布时间是否落在目标赛季附近；③ 标题是否含同名影视作品词；④ 时长/账号类型是否像搬运号**。其中①②两个硬筛子能一步干掉大部分同名污染。

污染与删帧要在过程记录里写明（否则后人会重犯）：哪些关键词被污染、你用什么筛子把它分开了。

### 3.3b 前景/背景混淆（把别人的道具当主体构件）

实测反例：一个“杆 + 球”形状被当成主体顶部构件，后来逐行像素扫描发现它位于主体**前方偏下**、更可能是**前景角色手里的道具**。一旦误归因，就会凭空多出一个构件。形状实测为**锥形杆 + 宽帽**（宽度比 0.09 / 0.47），并非“细杆 + 小球”——**形状描述本身就是可被推翻的**。

判定前的三问（任一项可疑就不能把它当主体证据）：
1. **遮挡**：若真装在那儿，它应被母体遮住一部分或与母体相接；它现在是贴在前面还是后面？
2. **深度**：它在画面里的高低位置与母体上那个位置的投影一致吗？
3. **帧间一致性**：若真是同一构件，两帧的**无量纲比**应当能互相解释（本例两帧比例矛盾，无法互解）。

两条通则（比三问更容易记）：
- **「在两帧里都看到了」不等于「两帧里是同一个东西」**。
- **同一画面里已出现过同类道具时，默认相似轮廓是道具，除非三问都通过**。

### 3.4 其他反爬与限流
- **403 / 质询页** → 换浏览器自动化（真 UA、真 JS 执行），不要靠堆 header 硬闯。
- **限流** → 表现常是“字段变空”而非 429：降速 + 重试，并把该现象写进脚本文档。
- **图被紧裁 / 带 HUD / 带水印** → 登记为**口径限制**，量测时必须框掉 HUD/UI。实测价值：某张参考里“24 个金色团块只有 8 个是建筑”，其余 16 个是小地图与头像。
- **紧裁会毁掉投影标定**：极值落在图像边界时解出的投影基底不可用（实测：同图内 1 m = 67 px 而 2.75 m = 225 px，自相矛盾）。

## 3.5 参考包必须可复现（取证脚本的三模式 + 完整性清单）

参考包的“可复现”不是“我写了脚本”，而是**能被验证**。推荐三个模式 + 一份清单：

| 模式 | 行为 | 期望结果 |
|---|---|---|
| 首次运行 | 缺什么下什么 | 下载字节的 md5 与既有记录一致 |
| 重复运行 | 已存在且大于阈值则跳过 | 0 下载、全部 skip（**幂等**） |
| `--verify` | 只读不写，重拉并比对 | 逐条报告“URL 仍能产出这些字节” |

- 另存一份 `_src/_md5.json` 作为完整性清单。
- **md5 不符时脚本必须拒写**（而不是静默覆盖）。这条让“CDN 换了图”能当场暴露，而不是几轮之后才发现 md5 链已无法回溯。

### 3.5.1 三类产物、三种校验（不要一律套 md5）

实测：一次 `--verify` 一律套 md5 时**误报 14 条 DIFF**，查下去发现是两类**正常波动**被当成事故。分类后 57/57 一致。

| 类别 | 校验方式 | 实测理由 |
|---|---|---|
| `asset`（图 / 官图 / 地图元数据） | **md5**（三方相等） | 字节稳定 |
| `api`（实时帖子 JSON） | **结构指纹**（如 `md5(subject + 字段列表)`） | **同一帖两次拉取长度相同、md5 不同**（浏览数/时间戳等现场字段在变） |
| `asset-reencode`（CDN 重编码资产） | **像素**（同尺寸 + 平均绝对差 ≤ 1） | 实测像素平均差 **0.00** 而 PNG 字节涨 **35%**（重编码） |
| HTML 页面 | **规范化内容哈希**（投影成域结构串） | 页面含时间戳/广告位/nonce，字节级必然漂移 |

推论：**字节级完整性只在“字节确实稳定”的产物上成立**。真换图 → `DIFF`；重编码/活响应 → 归为已知波动。

### 3.5.2 校验必须是**三方**对比（否则闸会谎报 ok）

实测事故：`--verify` 第一版只比“**重拉 vs 清单**”，**从未读磁盘文件**。于是“把磁盘文件末尾添 1 字节”的反向测试竟报 `ok` —— 闸没检它声称要检的东西。

正确做法：**URL、磁盘、清单三方对比**，并区分三类失败：
- `DIFF` —— URL 不再产出磁盘那份（重拉 ≠ 磁盘）
- `LOCAL` —— 磁盘变但 URL 与清单仍一致（本地被改）
- `api-DIFF` —— 活接口的图列表/标题变

反向测试的负样本就用“篡改磁盘字节”，期望得到 `DIFF` + 非零退出。

### 3.5.2 空输入哈希 = 永远不会失败的假绿灯

（规则与失败模式命名见 `10` I-01b；本小节只记现场事故。）

**这是本节最阴的一个坑**：当规范化输入合法地可为空时，哈希会恒定等于**空串的 md5**（`d41d8cd9`），于是永远“通过”。实测：某条目页根本没有蓝图网格 → 规范化串为空 → 哈希假绿。

规则：**任何校验都要先断言“输入非空且非退化”**。输入为空时该条目必须标为 `not-applicable` 并**不计入通过数**，不得当作绿灯。

### 3.5.3 完整性门禁同样必须做反向测试

“拒写闸”不能只声明它能拦：**在沙箱里把一个文件改成与清单不同的字节，验证脚本拒写且文件未被改动**（实侧输出形如 `REFUSED: on-disk != manifest <path> (disk …, manifest …)`，exit=1）。
与帧门禁的负样本规则同源：**每道闸都要有一个它能拦住的负样本**。
- 缺失的取证脚本本身就是缺陷：brief 里要求了 `_harvest.py`，但接手时目录里可能根本没有它——**接手第一件事是清点脚本是否齐备**。

## 4 主数据优先序（与 `02` 的注册链一致）

- 块级 / 矢量级主数据（逐层方块蓝图、等高线、房型图、尺寸链）**优先于**任何渲染图或截图的裁剪读法。
- 渲染图用于**剪影、读法与配色**；**不用于逐格定位**。
- 两者冲突时先问：**这个渲染读法能否被投影重叠或裁剪解释**？能解释就不要用它推翻主数据；不能解释且多张图同向，才动主数据，并走变更流程。

## 5 零结果与降级的登记格式

```text
渠道 | 关键词/动作 | 结果数 | 结论
```
示例：

```text
官方账号扫描 | 目标建筑图 | 9 张均为角色周边商品图 | 结构层数未获 A 级确认（永久已知局限）
官方视频抽帧 | 主体几何 | 1 张（宣发 CG，有 VFX 外溢） | 可作外形方向旁证，不可作直径量测口径
```

## 6 证据等级与“能不能用来量”是两件事

一条证据可以既是 A 级、又**不适合量某个量**（例：A 级宣发 CG 的发光环直径受 VFX 影响）。
所以来源表里除等级外，还要写**用途**；量测前先声明“这张的口径为什么干净”。

### 6.1 “口径干净的全景参考”验收清单（想要什么就按这个找）

需要整栋轮廓/层数/相对宽度时，一张能用的全景参考要同时满足：
1. **整栋入画**（不被画面裁掉——紧裁图连轮廓最宽处都无法无歧义确认）；
2. **中轴无遮挡**（前景角色/道具/建筑/树不能压住中轴）；
3. **画面内有可标定尺度**（地平线、已知宽度的构件，或同图内可自校验的标尺）；
4. **可识别是否含 HUD/水印/UI**（含则先框掉，再判断建筑面积）。

缺任一项，就不要拿它去量“绝对值”，最多拿它当**方向性旁证**（并写明是旁证）。

### 6.2 两类资料、两类关键词
需求分两层，搜法也应分两层：**整栋/平面**类资料（轮廓、层数、足迹）与**构件近景**类资料（材质、形制、颜色）。
实测：把一个对象的 14 族关键词逐族记账后，**只有“对象名”那一族产出 A/B 级可用几何**，其余大多数族（剧情/攻略/捏脸/壶内复刻/现实同名地标/同人）产出为 0。
所以：**分层搜（剧情 / 攻略 / 壶内或复刻 / 现实同名 / 同人）并逐族记账**，不要混在一轮里——否则你无法区分“没找到”与“被污染”。

### 6.3 镜像站“能打开”≠“有内容”
实测：同一镜像站的两个页面**字节数完全相同且无正文**（模板站壳）。所以取文时要**验证正文长度**，不能只看 HTTP 200 与标题。

## 7 收尾自检

- [ ] 每条几何都能指回一个证据 ID（未覆盖的构件不做，并登记）
- [ ] 来源表含等级 + 用途 + 抓取日期 + 落盘路径
- [ ] 抓取脚本可重跑且幂等；失败通道写在 docstring
- [ ] 零结果有登记
- [ ] 量测用的帧都声明了口径干净性
- [ ] 报告里的数字都能在落盘件上复算
