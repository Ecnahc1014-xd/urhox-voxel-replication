## 3. 空间语法与锚点

主轴与空间序列（单一主轴，中途两次折向）：

```text
南石桥 → 双塔城门 → 主街爬升 → 喷泉市集（T1）
       → 西折上骑士团（T2） → 神像广场 / 西风大教堂（T3）
```

- 地形形态：早期矩形台地 → **梨形岛、三级高程（T1/T2/T3）、西侧骑士团凸出、东侧港口缺口**（口径：一页纸“已经完成的努力”；as-of 2026-09-18）。
- 高程关系：水面、桥面、T1/T2/T3、教堂与风车的高程关系由 `MD-02_南北剖面` 承载（口径：SOP §5.1；as-of 2026-09-17）。
- 西侧：骑士团位于主轴西侧；图书馆为西侧独立体量（口径：执行层 Skill G3–G4；as-of 2026-09-18）。
- 北侧：教堂北侧为墓园（同一口径）。
- 东侧：**东港必须与城墙开口连续**（同一口径；港口/钓鱼协会曾是语义补全目标，见 SOP §17 阶段 A）。
- 阶段 D 已逐项调整的地标：三座风车、歌德酒店、骑士团、图书馆、教堂、神像广场、墓园（口径：SOP §17；as-of 2026-09-17）。
- 场景层级固定为一级分组 `Mondstadt` → `Terrain` / `Walls` / `Landmarks` / `Houses` / `Props` / `Lighting`；允许的二级语义分组含 `Approach`/`Civic`/`Harbor`/`NamedBuildings`/`StreetLife`/`Residential`/`Vegetation`/`Shore`/`Terraces`/`PracticalLights`（口径：SOP §9；as-of 2026-09-17）。
- 命名：地标用语义名（例 `FavoniusCathedral`）；评分体积与细节体积用后缀区分（例 `EastPier` / `EastPierDetail`）；动态实例带用途与序号（例 `PhysCrate1`）（同一口径）。
- 装饰纪律：摊位、路灯、树木、道具必须避让硬锚点与主通行带；不得用规则同心圆或机械排屋替代真实街区（口径：SOP §8 G5；as-of 2026-09-17）。

## 6. 未关闭风险（as-of 2026-09-18）

按源文件原文登记，未关闭即未关闭，不得被“当前布局已通过”掩盖：

1. **静态挖洞碰撞未闭环（P0）**：几何重建已确认，但 Jolt 静态碰撞是否在所有情况下同步形成可穿越洞口，尚缺**确定性自动化验收**（口径：SOP §2.3 第 1 条 + 一页纸 P0-1）。
2. **验收产物非原子归档（P0）**：最新一次 PIE 可能把 `mondstadt_projection.tsv` 写成零字节；必须“指标、投影源、叠加图”同轮生成、非空、可追溯、带 hash，禁止空 TSV 覆盖有效结果（口径：SOP §2.3 第 3 条 + 一页纸 P0-2）。→ 本 Skill 用 `scripts/build_evidence_manifest.py` 做大小/hash 清单，正是为覆盖此风险。
3. **目标硬件性能预算未冻结（P0）**：FPS、峰值内存、首建时间与破坏后重建延迟均未冻结；“没有预算，不判定可交付”（口径：SOP §2.3 第 6 条、§15 + 一页纸 P0-3）。
4. **旧资源 UUID 缺失警告**：编辑器/运行时仍有告警，未阻断核心体素结果，但发布前应清理或建立白名单（口径：SOP §2.3 第 2 条）。
5. **超大源文件**：`scripts/mondstadt.lua`、`scripts/buildings.lua` 超 2,000 行，下一次结构性开发前应按领域拆分（口径：SOP §2.3 第 4 条）。
6. **文档债务**：部分旧注释仍写“地形/建筑不可破坏”，与 v107 实际行为不一致（口径：SOP §2.3 第 5 条）。
7. **引擎 API 契约问题**：动态碎块可能已有物理代理但没有渲染几何；项目以 `MarkGeometryDirty()` + `RebuildGeometry()` 绕过（口径：SOP §2.3 第 7 条 + §12 失效模式表末行；前提：该 Runtime 版本，升级后必须复测）。
8. **未验证项汇总**：`poi_schedule.json` 的 27 项逐条清单、项目级“只读库”清单、复刻范围精确多边形、27 项锚点 RMSE 的加权口径——本案例文件均标 `UNVERIFIED`，需要时回原工程读取，不得由本文件推定。

**结论边界（引用一页纸，as-of 2026-09-18）**：空间复刻已达可继续生产水平，但“在静态挖洞碰撞、验收产物完整性和目标硬件性能未闭环前，不应对外宣称最终交付完成”。下一个动作是把“做出样机”推进到“建立可测量基线”，而不是继续增加装饰量。
