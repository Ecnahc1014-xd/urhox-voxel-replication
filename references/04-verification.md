# 四类独立验收、投影/剖面/占用/接地/破坏与多机位回归

本文件只描述**与具体对象类型无关**的验收方法。所有阈值、POI、机位、路径都必须来自项目参数表或案例文件；本文件不预设任何具体数值。文中“G0 冻结/冻结阈值”仅表示验收口径已登记并可复现，不表示 AI 主动冻结模型、材质、通道或后续保真推进。

## 0. 适用前提与总则

- 验收对象是**最终运行结果**，不是生成意图。参考数据与生产数据必须独立；同源数据只能做内部一致性检查，不能证明复刻忠实度。
- 四类门禁**分开验收**，任何一类不得替代其他三类：空间忠实度、体素工程质量、视觉/语义质量、玩法/物理质量。
- 每类门禁输出**独立的检查表**与本类结论；不允许用一句“整体通过”把四张表合并。
- **门禁准入上限（唯一出处）**：全局**可拦人**的门禁只有两套——本文件的四类发布验收，以及 `19` 的入包闸 **H1–H6**（H1 角色 / H2 可量测性 / H3 部件数 / H4 正交基底 / H5 参考同一性 / H6 对象在场性）。其余一律是**仪器**（`10`：只产读数、只报警、不停手）或**批次体检脚本**（一条命令 + 退出码）。
- **新增可拦人门禁的前置条件（两条同时满足）**：① 该失效类别在近两批实测中**发生过 ≥1 次**；② 其返工成本 **≥1 轮**。不满足 → 只能做仪器。**且编号不得复用**（沿用既有编号体系；编号冲突 = 规则冲突，2026-09-24 在 `19` 就发生过一次 H4 撞车）。
- **门禁必须机器化且防误报**：一条命令出 PASS/FAIL，带**白名单与时间窗**（防止把引擎自带资产/历史产物误判）；**禁止**把门禁写成要求人/agent 逐项手工核对的检查表（那是效率杀手）。
- 所有具体数值以 `<...>` 占位符出现。阈值在**基线冻结时**确定，不得为当前模型临时调整。参数表未定义的一律标 UNVERIFIED，不得由验收者发明。
- 指标改口径时，同时保留旧值、旧定义、修订原因与新值；**不得把评分语义变化写成模型改善**。
- 静态解析、离线计算、结构对账不能推出“运行时正确 / 画面已修复 / 物理已生效”。凡结论只来自静态证据，必须写明“未跑运行时 + 静态关系推断”。
- 某行为本轮没有产生新样本时，只能写“无法判断改善或恶化”，禁止写成“无变化”“已修复”。

### 3.1 高度来源 provenance 表（C2 / C3 与表 A5 的前置）

“能测”的下一步是“知道这个数是从哪来的”。**实测拟合 / 量化 / 声明**三层可以同时存在于一个高度场里；不允许的是**逐像素分不出哪块是哪层**。任何高度读数（`height_m` 一类数组、图纸高程标、体素层高）入档时必须同时登记：

```text
height_source   survey | fit_from_survey | official_data | band_quantized | declared_fill | stylized_declared | derived_other
value_kind      measured | fitted | quantized | declared
error_bound     误差口径（绝对值 / 百分比 / 留出验证读数 / 不可估）
source_layer    逐像素可查的分层掩膜（同一栅格的 layer_id 图；缺这张图即“三层不可分”）
support_bbox    实测支撑范围（点集覆盖的 xz 范围与高程区间）
reference_id    对应 source_id 或数据件
verified_by     谁核过、什么时候、按什么规则
```

| height_source | 含义 | 使用边界 |
|---|---|---|
| `survey` | 实测（激光 / 水准 / 剖面读取） | 可直接参与高程误差判定 |
| `fit_from_survey` | 由实测点拟合（含网格化/插值） | **必须报留出验证读数**（如“留出 20% 有 98.4% 落在 ±40 m”）并给 `support_bbox`；未覆盖区间不得当作已实测 |
| `official_data` | 官方数据（DEM / 等高线 / 官方剖面） | 参与判定前先跑 `02` §4.6（留出法 + 独立一致性） |
| `band_quantized` | 按步长量化成台地（含为还原风格化环台阶而做的处理） | 属于**风格化处理**，必须入注册表（`02` §4.5 变更流程），不得当实测 |
| `declared_fill` | 声明值回填（如“岸线/小岛按 2 m 处理”） | **声明值**：不得被下游当实测引用（不许拿它算“p50 = … m 实测”） |
| `stylized_declared` | 风格化声明（设计事实） | 只支持“设定如此”，不支持与真实地形的相似性结论 |
| `derived_other` | 其它反演 | 必须写明反演口径与误差，同上按声明值处理 |

- 动作：缺任一字段 = `UNVERIFIED`；此时 C2（剪影）与 A5（高程分层）**不得判 PASS**，最高 `PASS-WATCH`。
- 动作：**同一个场里有多种 `height_source` 时，必须给 `source_layer`（逐像素 layer_id 栅格）**；给不出就是“三层不可分”，下游引用一律按**最低可靠度的那一层**记（不得按最高那层）。
- 动作：**样本代表性检查**：`support_bbox` 之外的区域（低地 / 海岸 / 离群区）必须显式标为“无实测支撑”；基于无支撑区得出的结论（均值/分位数/分层）不得写入“实测”叙述。
- 动作：`value_kind == declared/quantized` 的高度场，或“多层不可分”的场，必须在同一轮跑 `10` I-12 的形态读数并随轮归档；读数命中 `TERRACE-UNPROVEN` 时 C2 记 `UNKNOWN`（不得记 PASS），下一轮补同轴参考或官方剖面。
- 动作（禁止项）：**自证引用**——拿自己的高度场当作“官方/实测证据”回写同一批结论（实测例：用自己的场去证明“官方 dark = 山地林带”）。引作证据的高度场必须能追溯到一个**外部** `reference_id`。
- 验收：任取一个高度读数，都能回答“它从哪来、是实测/拟合/量化/声明、误差口径多少、被谁核过、在 `source_layer` 里是哪一层”。
- 实证（负样本，**已更正口径**）：某路的高度场本身是**合格拟合**（r17 用 1,187 个世界地面点主动**证伪**“色带 = 海拔”，r18 留出 20% 有 98.4% 落在 ±40 m）——问题在后面：①点集最低 151.4 m，低地/海岸无样本；②环带区按 15→30 m 步量化成台地但未入注册表；③三种来源逐像素不可分；④下游拿它当实测/当官方证据。形态读数（陆地 ≥200 m 占 53.2%、25–200 m 仅 4.9%、8 机位 8/8 PASS）现在应读作“高原台地 + 台面，**可能是对的**，但无任何独立证据能判它对错”。

## 4. 表 D — 玩法/物理质量检查表

验证“能不能玩、物理对不对”。每次实验固定：对象、射线起点/方向、工具、半径、材质、帧数、角色位置。

| 检查项 | 可测指标与阈值口径 | 采集方式 | 失败处置 |
|---|---|---|---|
| D1 静态洞碰撞反馈 | 挖穿静态地面后角色掉落（布尔） | 固定路线/落点，隔离碎块后复测 | 判定碰撞代理问题，重建代理 |
| D2 动态体三证合一 | 三证全部满足（见第 5 节） | 破坏烟测日志三路记录 | 任一证缺失即判失败，不得放行 |
| D3 碎块峰值与回收 | 峰值 ≤ `<N_Peak>`；回收率 ≥ `<T_Recycle>` | 逐帧采样碎块计数 | 调预算与回收逻辑 |
| D4 碰撞代理重建 | 改动后代理已重建（布尔，含时间戳） | 代理日志与网格变更事件对照 | 补重建调用，重测 D1 |
| D5 主路线可通行 | 全程可通行（布尔）+ 卡点计数 = 0 | 路线自动行走/射线落点 | 修几何或净空，不动注册 |
| D6 入口可达性 | 注册入口可达计数 = 入口总数 | 路径搜索到入口命中 | 修台阶/门槛/装饰阻塞 |
| D7 射线命中一致性 | 命中结果与几何/代理预期一致（命中率 ≥ `<T_Ray>`） | 固定射线集批量投射 | 对照几何与代理，定位错配层 |
| D8 碎块隔离复测 | 隔离/清场后结论与 D1 一致（布尔） | 清场或隔离碎块后重跑 | 不一致时以隔离结果为准，重查代理 |

“角色被下落碎块接住”不能证明静态洞碰撞正确。

## 5. 破坏验收三证合一（硬规则）

破坏类改动必须同时满足三条，缺一不可：

1. **数量或占用变化**：`solid count` 或占用表发生**预期**变化（记录操作前后值）。
2. **可见几何变化**：`vertex count` / dirty 状态 / 网格重建任务更新，画面上能看到洞或碎块。
3. **碰撞反馈**：角色或物体的实际反馈符合预期，例如挖穿静态地面后确定掉落。

每次记录必须包含：

```text
1) 操作前后 solid count
2) 修改体素数
3) vertex count / dirty state / mesh job
4) 静态或动态碰撞代理是否重建
5) 角色或物体的实际反馈
6) 碎块峰值与回收结果
```

配套硬规则：

- **有物理代理不等于有可见几何。** 动态体必须检查 `solidCount > 0`、`vertexCount > 0`、几何 dirty 已清除、重建任务收敛，四项都满足才可声称“看得见”。
- 动态体素写网格后按引擎兼容路径执行“最终化为动态 → 标记几何脏 → 重建几何”；局部动态修改后再重建动态代理。
- 不把 beta 中不稳定的伤害/填充类接口作为唯一玩法路径；脚本级打洞/填充必须有独立日志与烟测。
- 只证明几何没证明碰撞的测试，判为失败。

## 6. 多机位回归

- 固定机位集按**机位分层**选取（分层定义与按对象类型的机位表见 `references/06-visual-fidelity-loop.md` 第 6 节与 `references/08-subject-classes-and-scales.md`）：至少覆盖全局层、序列/关系层、关键特征层、近景材质层各一组。具体清单由参数表给出的**机位清单专项文件**承载（文件名写在参数表，每个机位须含位置、朝向、FOV 或正交尺寸、分辨率、clipping、时间、**灯光组主数据版本、RenderPath 版本、本轮采集通道（A 无光照 / B 光照契约 / C 成片）**、参考图版本共 11 项，后三项的口径见 `16-lighting-and-postprocess-fidelity.md`）。
- 相机位置、朝向、FOV 或正交尺寸、分辨率随版本保存；每次比较必须同机位同参数。
- 回归流程：冻结机位参数 → 同轮统一截图 → 与上一轮同机位对比 → 只登记变化项 → 变化项回落到对应检查表（空间/工程/视觉/玩法）。
- 跨轮对比禁止引用行号或文件字节数做判断；持久锚点用符号名、固定字符串或固定搜索的**命中条数**。字节数只用于同一轮内前后对比。
- 一轮只改一个类别；若必须改注册变换，视为新基线并重跑全局门禁。

### 6.1 机位清单 11 项：逐项判据与惯例起点

**总规则：第 7–11 项任一不等 ⇒ 该组对比作废（布尔，无中间态）。** 第 1–6 项是复现类，同存档复现应取 0；只有“从参考图反推位姿”时才允许容差，且必须声明**沿视线方向的自由度为不可辨识**（`14` §4.3）。

“惯例起点”列是外部工程实践的常见值，**不是本工程门禁**；写进门禁表前必须在本工程留下负样本（同上 `10` I-04 的协议），并把实际取值登记到参数表。

| # | 项 | 判据形态 | 惯例起点 | 说不清就不能宣称什么 |
|---|---|---|---|---|
| 1 | 位置 | 同存档复现 / 参考反推，两种情形分开记 | 同存档 `<T_CamPos>`=0；参考反推横向 ≤1.5% 图宽，深度方向**不可辨识** | 不得用单图反推的位姿宣称“空间位置正确” |
| 2 | 朝向 | 同上 | 同存档 `<T_CamRot>`=0°；参考反推时按“命名特征点漂移 ≤2% 图尺寸”换算 | 同上 |
| 3 | FOV / 正交尺寸 | 同上 | 同存档 `<T_CamFov>`=0；参考反推 ≤1.5% | 不得因“看着差不多”接受不同 FOV 的两帧对比 |
| 4 | 分辨率 | **精确相等**（含像素格式与色彩空间） | `<T_CamRes>`=0 px | 不同分辨率不得直接逐像素比（只能重采样后比，且重采样方式入档） |
| 5 | clipping（near/far） | **精确相等** | `<T_CamClip>`=0 | far 变化会改变雾与剔除，跨 far 的对比无效 |
| 6 | 时间 | 静态场景写“冻结”；含动态元素时比**模拟步序号** | `<T_CamTime>`=0 步 | 不得用“差不多同一时刻”的两帧做逐像素对比 |
| 7 | 灯光组主数据 | 布尔：ID + 版本 + 内容哈希全等 | `<T_LightContract>`=1（全等） | 契约不等 ⇒ 一切图像相似度指标作废 |
| 8 | RenderPath | 布尔：资源名 + 哈希 + **启用 tag 集合**全等 | `<T_RenderPath>`=1 | 换 tonemap/bloom 等于换相机，旧基线全废 |
| 9 | 后处理开关快照 | 布尔：Zone 后期字段哈希全等（字段清单见 `16` §6） | `<T_PostFXSnapshot>`=1 | 不得用成片（后效全开）判几何 |
| 10 | 采集通道 | 布尔：**A 无光照必存**；B（光照契约）按需；C（成片）用于展示 | `<T_ChannelSet>`=1 | 只有 C 通道 = 该机位无几何证据 |
| 11 | 参考图版本 | 布尔：参考内容哈希全等 | `<T_RefVersion>`=1 | 参考换版 = 全部基线重立 |

配套导出：本轮机位表快照必须与上表**同构、同字段数（11）**；少字段或字段名不一致时，清单脚本应报错而不是补空值。

## 7. 产物一致性与证据链

同轮验收包共享一个 run ID，至少检查：

- 文件存在且非零；
- JSON/TSV 可解析且有预期行数；
- 指标中记录的输入哈希与投影文件哈希一致；
- 叠加图的尺寸、注册版本与指标相同；
- 构建日志时间晚于源脚本变更；
- 场景根节点数量正确。

验收源文件、指标、叠加图与日志先写临时文件，确认非空、可解析、互相对应后再原子替换；不能只归档派生 JSON。清单脚本发现零字节文件时必须返回非零退出码，正式验收不得忽略。

## 9. 适用对象类型与裁剪

四张检查表的取用按对象类型裁剪（分类与尺度见 `references/08-subject-classes-and-scales.md`）；裁剪的是**检查项**，不是证据标准。

| 表 | 全表适用 | 以部分子项为主 | 多为裁剪 |
|---|---|---|---|
| A 空间忠实度 | 城市/聚落、街区/场地 | 单体建筑（轮廓与尺寸链）、室内（房型尺寸与层高）、自然景观（高程与岸线）、道具载具（轮廓与比例） | — |
| B 体素工程质量 | **全部对象类型与尺度**（不得裁剪） | — | — |
| C 视觉/语义 | 城市/聚落、街区/场地 | 单体建筑（剪影/立面/材质）、室内（净空比例与陈设）、自然景观（坡面/水岸/植被）、道具载具（剪影与部件拓扑） | — |
| D 玩法/物理 | 城市/聚落 | 街区/场地（通行与净空）、室内（通行与净空）、道具载具（接地与重心）、单体建筑（多为裁剪） | 无玩法/无破坏时整体裁剪，但须登记“本轮不做玩法验收” |

**不可裁剪项（与对象类型、尺度无关）**：注册同源性、占用重叠、悬浮/下陷/越界、接地或贴合、根节点唯一性与构建幂等、固定机位参数可复现、动态体有可见渲染面、指标与证据可追溯；破坏“三证合一”仅在玩法含破坏时适用。

裁剪写入格式（参数表一行，缺任一段视为漏检）：

```text
裁剪项 | 理由 | 替代检查项 | 确认人
```

无替代检查项的裁剪，只能将对应门禁最高设为 `PASS-WATCH`；不得以“该类对象不需要”当作放行理由。

## 本文件的通用性边界

- 本文件只给检查项、口径形式与处置方式；全部阈值与机位清单以占位符出现，须由项目参数表填入，未定义项标 UNVERIFIED。
- 四张表的**检查项集合是建议下限**，不是固定上限；项目可按自身风险增项，但不得删减四类分开与三证合一两项硬规则。
- 表 B、表 D 依赖引擎提供的占用审计、碰撞代理与网格重建能力；换引擎前须先确认存在等价机制，否则对应检查项只能标 UNVERIFIED，且不得外推结论。
- 表 C 的特征覆盖与近景语义属人为判定，存在主观性；因此它只用于排优先级与回归对比，不单独用于放行。
- 本文件不提供任何引擎 API、脚本路径或具体数值；其中与引擎相关的路径与调用以项目文档和引擎版本为准。
- 本文件不替代 03 的建模语法；建模通过不等于验收通过，验收通过也不等于交付完成。
