# 视觉保真度循环：固定机位缺陷关闭

本文件只描述**与具体对象类型、具体项目无关**的迭代方法论。地名、关键特征名、机位名、指标、阈值、路径一律用占位符；本文件不预设任何具体数值。

## 0. 适用前提与占位符

- 对象：**任意复刻对象**（城市/聚落、街区/场地、单体建筑、室内空间、自然景观、大型道具载具、混合场景；分类与尺度见 `references/08-subject-classes-and-scales.md`。引擎族默认 UrhoX / TapTap Maker；换引擎时先确认坐标系、渲染通道与截图能力，确认前不外推本文件结论）。
- 基线原则（六条，缺一不可）：**同机位、同相机参数、同注册、同口径、单变量、可回滚**。
- 本文件不判断“好不好看”，只提供“哪一轮有资格被记为改善、凭什么、风险是什么”的判定框架。
- 阈值与指标定义来自项目参数表；未登记的指标一律视为口径未定义，不得用于判定通过。

### 占位符

```text
<RUN_ID>          本轮唯一运行编号
<BASELINE_TAG>    版本基线标签（可被新证据替代）
<SHOT_ID>_<LAYER> 固定机位 ID（含分层，例如 <SHOT_ID>_L0）
<DEFECT_ID>       缺陷编号
<T_METRIC>        指标阈值
<LANDMARK_x>      关键特征占位（A/B/C……）
<SEQUENCE_x>      空间序列占位（入口/主轴/开放空间/水系）
```

## 1. 目标与判定口径

图像保真度不是“体素数量上升”，而是让参考中的**轮廓、空间层级、地标读形、材质分区、光照氛围与玩家视线**在固定机位下逐轮更接近。

**误差必须先分流为两类**（分流规则与外观轴刻度见 `16-lighting-and-postprocess-fidelity.md`）：

- **几何类**：剪影、比例、位置、构件缺失——只在**无光照通道（A）**上判定，进几何回归集。
- **外观类**：光照方向/强度、阴影、雾、材质响应、后处理——只在**光照契约已记录且后处理停用**的通道上判定，**不得进几何回归集**，也不得用来搎盖几何缺陷。

工业判定：只有在**至少一个已登记视觉误差下降**、相关证据可复核、且没有触发更高优先级门禁回退时，本轮才允许记为“保真度提升”。

以下各项**本身不构成质量结果**，只能作为过程量记录：体素总数、节点数、截图张数、单次运行成功、单张透视截图好看。

## 2. 每轮记录输入基线与必产输出

### 每轮输入（开始前记录；用于复现和归因，不是最终冻结）

```text
<BASELINE_TAG>
固定机位包（位置、朝向、FOV 或正交尺寸、分辨率、clipping）
参考叠加/差异板（版本号）
上一轮 metrics
当前最大误差对象
本轮参照项清单
本轮唯一目标（只允许一个）
时间与灯光参数
指标口径版本
```

任一项变化都必须新建 `<RUN_ID>`，不得直接覆盖上一轮。

### 每轮输出（缺一不可）

1. **变更单**（字段见第 9 节），写清根因、改动、本轮参照项与回滚点；
2. **原图 / 改后图 / 差异图**三件套，同机位、同相机参数；
3. **指标前后值**，同时给**均值与最差项**（只给均值视为无效）；
4. **占用与网格结果**（涉及几何改动时必给）；
5. **运行时证据**（涉及场景/动态体/烘焙时必给）：PIE 或烘焙日志、可见画面；
6. **未关闭风险**与**下一轮唯一动作**；
2. **视觉读入记录（不可省）**：本轮的 `改后图` 与 `参考叠加/差异板` 必须**以图像输入（视觉）方式打开过**，并给出 **≥3 条部位级差异**，格式：`参考有什么 / 我缺什么 / 在哪个部位`。
   **纯数值（SSIM / Δpix / 均值 / 边缘一致度）不得替代这一步**；无图像读入的轮次记 **`NO-LOOK`**，本轮不计为保真度提升。
   该记录是**自报制**（机器无法核验是否真读过图）；审计抽检只认入档记录，缺记录或三条差异非部位级的轮次一律按 `NO-LOOK` 处理。

证据包必须原子归档、非空、可解析，并保留文件哈希或等价版本指纹；不允许只归档派生的汇总数据。

## 3. 标准循环

```text
记录版本基线图像与指标
  → 归类最大视觉误差
  → 选择一个修复层级
  → 修改最少的主数据
  → 运行最小相关回归
  → 运行必要的全局门禁
  → 用同机位重新出图
  → **以图像输入打开改后图与差异板，写出 ≥3 条部位级差异（NO-LOOK 闸）**
  → 记录前后差异、证据与未闭环风险
  → 接力下一轮
```

**`NO-LOOK`（硬规则）**：**只出图不读图的轮次不算进展**。数值指标与“哪里缺”经常脱钩（实测：某络舰单轮 +18,330 格而 Δpix 仅 0.45%）。
读图记录必须落进当轮证据：读了哪两张、写出哪三条差异、据它们选了哪个修复层。
「部位级」的定义：能指到具体构件与方位（如“参考中下区域是连续大甲板，我方是散开的三艘”），而不是“整体有点像/不太像”。

前提与适用范围：固定机位与已记录的相机参数是本循环成立的前提。机位、FOV/正交尺寸、分辨率、时间、灯光、clipping 中任何一项变化，图像差异都不可用于判定；这只是比较条件，不是禁止生成新机位或新版本。

## 4. 阶段门禁

| 阶段 | 门禁目的 | 必须证据 | 通过条件 |
|---|---|---|---|
| F0 基线记录 | 保证本轮可复现 | 唯一 `<RUN_ID>`、输入哈希、机位/时间/分辨率清单、基线清单 | 输入一致，证据包非空且可解析 |
| F1 注册与轮廓 | 防止全局比例漂移 | 注册平面叠加、正交图、边界/台地/主轴审计 | 边界、台地、主轴无未授权全局漂移 |
| F2 空间与地标 | 保证位置关系与接地 | 锚点/footprint/道路/净空指标、地标对照板 | 地标中心、footprint、接地、道路关系通过 |
| F3 剪影与语义 | 保证固定机位可读 | 中景机位前后图、差异图、最差对象清单 | 主地标剪影成立，主路与开放空间不被切断 |
| F4 材质与灯光 | 保证近景层次稳定 | 近景机位包、材质分区表、灯光参数与异常记录 | 无黑墙、严重过曝、色温失控或随机噪声 |
| F5 运行时图像 | 保证交付画面与离线图一致 | PIE 图像、日志、烘焙输出、动态体/碎块检查 | 无重复根、无空几何、无渲染伪影，流程可重复 |

门禁状态取值与迁移规则见 `00` §5（**唯一权威**）；本循环只用其中的四态，`EXPLORATORY` 不得进入正式基线。

- `EXPLORATORY` 只能用于试验，不得进入正式基线。
- `BLOCKED` 必须停止向后传递，先关闭阻断项再继续。

## 5. 视觉误差分类与修复顺序

| 误差类型 | 典型症状 | 先改什么 | 不要先改什么 |
|---|---|---|---|
| 全局轮廓 | 整体过瘦/过胖、边界形状错误、水系肩部缺失 | 注册链、边界、台地布局 | 民居窗、灯光、随机装饰 |
| 空间关系 | 入口—主轴—地标—水系的序列不对 | 锚点中心、道路、台阶、开口 | 材质颜色 |
| 地标体量 | 核心地标过大/过小、天际线抢位 | footprint、层级、最高构件 | 增加更多细节体素 |
| 剪影 | 远景认不出核心地标 | 塔、屋顶、桅杆、外轮廓 | 室内小物件 |
| 中景语义 | 广场像空地、码头像木板、边界无围合 | 摊位环、系缆桩、路径、石栏、挡土墙 | 全局缩放 |
| 近景材质 | 墙/木/瓦/石混成一色、黑墙或高光异常 | 材质分区、调色板、粗糙度、灯光 | 改锚点坐标 |
| 视线可读性 | 装饰遮住主路或地标、画面拥挤 | 净空、密度、前后景层次 | 加更多装饰 |
| 运行时伪影 | 碎块不可见、烘焙重复、画面与离线图不一致 | 脏标记/重建、烘焙幂等、相机与分辨率 | 把问题归因于美术 |

默认修复顺序：**轮廓 → 空间关系 → 关键特征体量 → 剪影 → 中景语义 → 近景材质 → 软装饰**。

上表与上文以城市类对象举例；其它对象类型的等价失效模式（台阶化过重、水面穿地、通道不可过、部件比例失衡等）见 `08` 第 2 节与 `03` 第 14 节，修复优先级顺序不变。
**"前一级稳定"的判据（可测）**：该级对应的检查项全部达阈值，且最差项不低于基线；判定人与结论写入 `iteration_<tag>.md` 同一行，且**必须附该级检查项读数，缺读数不得写结论**。不达标则不得跳到下一级；若必须跨级（上级指标本轮无法测量），按 SKILL.md 第 3 节登记裁剪并将本轮状态降为 `PASS-WATCH`。

## 6. 机位分层

- **L0 全局识别**：顶视或全局正交、远景。只看整体轮廓、大尺度分层、主轴/主轴线、水系与边界关系。L0 不通过，禁止局部精细化。
- **L1 序列与关系**：主要进入路径、主体量之间的空间关系、关键开放空间。检查视线与叙事是否连续、关键路径是否被装饰切断。
- **L2 关键特征读形**：核心特征的正面与侧面、外轮廓、最高或最窄构件。检查 footprint/包围盒、接地、最高构件、塔/屋顶/桅杆类剪影。
- **L3 近景材质**：主体表面、结构件、覆盖层、水体、光源、衬景植被。检查色彩层级、粗糙度、光照、重复纹理与死黑面。

不同对象类型的机位集取用（分类见 `08` 第 2 节）：

| 对象类型 | 必有机位 | 特别关注的看点 |
|---|---|---|
| 城市 / 聚落 | L0 全局正交 + L1 进入序列 + L2 关键地标正/侧 + L3 街景 | 轮廓与网格、路网被切断、天际线抢位 |
| 街区 / 场地 | L0 场地正交 + L1 主轴线 + L2 主构筑物 + L3 铺装与小品 | 边界闭合、高差、通行净空 |
| 单体建筑 | 正立面、侧立面、四分之三、屋顶或俯视 | 剪影、层高与开洞比例、屋顶轮廓 |
| 室内 | 人眼高度主视、反向视、角落视 | 净空比例、通道通过性、家具穿插 |
| 自然景观 | 高空正交 + 贴地或近水面视 + 特征点视 | 坡面连续、水位与岸线、阶梯化 |
| 道具 / 载具 | 正交三视 + 四分之三 + 细部特写 | 剪影与部件拓扑、比例链、重心与接地 |

规则：

- 一个版本至少保留一组 L0、L1、L2、L3 机位。
- 本轮只改 L2 时，至少回归相关 L1 与一组 L0，避免局部收益破坏整体识别。
- 每轮至少比较一组 L0、受影响层级机位、一个邻近层级机位。
- 高风险对象或当轮结论要进 PASS 时，受影响层级至少**双机位或同机位两次采样**；单样本只支撑 `PASS-WATCH`。

## 7. 机位与指标登记

固定机位使用**稳定 ID**，例如 `<SHOT_ID>_L0`、`<SHOT_ID>_L1`、`<SHOT_ID>_L2`、`<SHOT_ID>_L3`。

每个 ID 必须登记：位置、朝向、FOV 或正交尺寸、分辨率、clipping、时间、灯光组、参考图版本。
不得用“差不多同角度”替代登记参数。

指标分三类记录：

- **空间指标**：锚点中心误差、footprint 重叠度、边界/分层比例、通行净空、占用与网格结果；
- **视觉指标**：轮廓、剪影、材质层次、最弱机位的人工判定与差异图；
- **运行时证据**：PIE/烘焙日志、动态体渲染、碰撞与通行结果。

硬规则（与 `04` §1 末段一致）：**平均改善、最差对象恶化时，状态不得高于 `PASS-WATCH`。**

## 8. 单变量与变更预算

一轮只允许改一类东西。按轮次类型限定可改项：

- **全局布局轮**：只改注册参数、边界、台地、道路或主锚点；必须重跑全局正交、道路、占用与全部代表机位。
- **地标轮**：只改一个或一组相关地标 footprint、构件层级或接地；本轮保持全局注册参数不变，若需变更则生成新版本。
- **语义轮**：只加路径、摊位、石栏、桩、箱桶、灯、旗、围合语法；不得改变硬锚点。
- **材质/灯光轮**：只改材质、调色板、灯光组、雾、阴影或曝光；必须回归近景黑墙、过曝与整体色温。
- **运行时轮**：只改动态体、几何重建、碰撞、碎块或 PIE 流程；必须保留上一轮图像基线做 A/B。

同一轮同时改城市宽度、地标尺寸、材质和灯光会失去因果关系；宁可多一轮，也不要交付不可解释的综合变化。

## 9. 缺陷分级与变更控制

- **V0 交付阻断**：注册关系错误、证据包为空或不可解析、PIE 重复根、关键烘焙失败、结果不可复现。
- **V1 身份与玩法**：主轴或核心地标严重失真，出现静态空洞，碰撞或通行错误。
- **V2 局部视觉**：单个 footprint、水系细节、剪影、材质分区或净空问题。
- **V3 收口抛光**：不影响识别、空间关系与玩法的微小装饰、色差或重复纹理。

规则：V0/V1 必须优先关闭；V2/V3 不得以牺牲 V0/V1 门禁为代价提前交付。

每个进入正式队列的改动都必须有变更单，至少包含：

```text
defect_id          缺陷编号
baseline_tag       基线标签
stage              阶段（F0–F5）
owner              责任人
severity           分级（V0–V3）
affected_shots     受影响机位
root_cause         根因
proposed_change    拟改动
frozen_items       本轮参照项（历史字段名；不表示模型永久冻结）
rollback_point     回滚点
acceptance_metric  验收指标与口径
```

## 11. 证据与统一命名

正式证据、截图包与运行日志使用 `07` §1 定义的 tag（**tag 方案唯一出处**）；本循环的 `<stage>` 段填宏观 G 编号（如 `G6`）。

```text
<project>_<object>_<stage>_<shotset>_<run_id>
```

要求：

- 同一 `<RUN_ID>` 下的原图、改后图、差异图、指标与日志必须保持**同一前缀**；
- 禁止使用“最终版”“最新版”“临时”等不可追溯名称；
- 每轮保留全部三件套，不要只替换最新截图；
- 证据先写临时文件，确认非空、可解析、互相对应后再原子替换正式文件。

## 12. 回归规则

- 机位、FOV 或正交尺寸、分辨率、时间、灯光、clipping 固定；否则图像差异没有意义。
- 参考叠加来自已记录版本的工程图，实际图来自**最终运行时网格**或 PIE 结果；不使用布局脚本的同源多边形自证。
- 记录均值与最差项：平均 footprint 变好但最低地标恶化，不能判定整体改善。
- 指标口径变化时，旧值与新值分栏记录；**评分口径改变不等于模型改善**。
- 某行为本轮没有新样本时，只能写“无法判断改善或恶化”，不得写“无变化”“已修复”，更不得伪造样本。

## 13. 回滚、版本基线与升级

- 出现 L0 回退、占用或净空门禁失败、运行时伪影、证据不可复现、指标口径未登记时，立即回滚到最近一个 `PASS` 基线，不在当前版本上继续叠加修补。
- 修改全局注册、坐标变换、主轴、边界或台地后，必须生成新的基线标签；局部变更不得悄悄改变全局注册。
- 连续两轮没有改善主问题（判据与升级阶梯见 `00` §4 第 4 条），或平均指标改善但最差对象连续恶化 → 升级为复盘项，重新确认根因与修复层级。
- 临时机位、手工删除节点、仅编辑器可见的修补、无日志的人工操作，一律不得作为正式验收证据。

## 14. 停止全局精细化的条件（不是 AI 主动冻结）

满足以下条件后，可以停止当前一轮全局精细化，转入局部收口；这只是当前工作分配，不是对几何、材质、通道或后续改进的自锁：

- L0 整体轮廓与主轴稳定；
- 边界、台地、道路、硬锚点与地标 footprint 通过门禁；
- 严格网格与占用审计通过；
- 主要机位连续两轮**无全局回退**（这是“可转入局部收口”的稳定性条件，与 `00` §4 第 4 条的“连续两轮无改善”是不同判据；若同时命中无改善，按 `00` §4 第 4 条升级）；
- 新增细节只改善近景，不再改变整体比例；
- 继续全局变形的收益小于引入注册漂移的风险。

经验性判据（非阈值）：当局部问题已经无法靠继续全局拉伸解决时，改进方向应转为**局部锚点、关键剪影、材质分层与运行时证据**。
